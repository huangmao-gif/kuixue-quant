# 葵学3.0 验证标准（写死，不改）

## 基准
- **沪深300当日涨跌幅**（不用上证指数，银行权重扭曲太严重）

## 收益定义
- **超额收益 = 组平均涨跌幅 - 沪深300涨跌幅**
- 绝对收益不算，只看模型贡献的部分

## 区分度检验：五档分组单调性
把评分结果按分数从高到低分5组（每档约20%）：

**验证前先剔除：**
- 当日涨停股（买入不可执行，虚增收益）
- 当日跌停股（卖出不可执行，虚减收益）
- ST/*ST（流动性陷阱，涨跌停板5%不可比）

剔除后再分5档：
- Q1：评分最高20%
- Q2：次高20%
- Q3：中间20%
- Q4：次低20%
- Q5：评分最低20%

**判断标准：Q1超额 > Q2超额 > Q3超额 > Q4超额 > Q5超额（递减）**

不是看Q1涨没涨，是看五档之间有没有排列关系。
如果五档随机甚至倒挂，因子组合就是噪音。

## 验证周期
- 单日不设硬阈值，只看方向
- **连续5个交易日（4/27-5/1）**
- 5天中4天以上保持单调递减 → 模型有初步区分度，值得迭代
- 5天方向随机 → 停下来换因子，不继续优化工程

## 数据质量
- 新浪PE/换手率 vs 东方财富口径未校验
- **周一先做一次交叉验证**：取10只股票，对比新浪和东方财富的PE/换手率数值
- 如果差异>20%，因子排名可能从根上就是错的

## 判断链路
超额收益 → 五档分组 → 单调性 → 连续5日稳定性

在这四步走完之前，模型"有效"或"无效"都是猜测。
