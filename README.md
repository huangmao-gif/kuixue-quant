# Kuixue Quant · 葵雪量化

A-share 量化研究项目：从个股追涨策略到大样本证伪，再到"先方向后个股"的 ETF 策略体系。
一个完整的"假设 → 大样本回测 → 证伪 → 重构 → 模拟盘/实盘验证"工程闭环。

> 本项目为研究存档。策略 v2.6 已被作者自己的回测证伪，最终以 ETF 方向策略实盘小仓位验证后主动终止。
> 仓库保留完整迭代过程，作为"先证伪、再证实"回测纪律的实证记录。

| 实盘验证 | 2026.06 | 新能源 ETF 小仓位实盘 | -6.1%，主动止损终止，完成闭环 |

## 核心教训（仓库存在的意义）

1. **短周期回测不可靠**——3 个月结论被 1 年数据整体推翻
2. **样本量过万才有统计意义**；必须跨牛熊周期验证
3. **正收益可能是市场 β 而非策略 α**（出招表概念平均 β=1.49，Jensen's α 仅 +0.21%）
4. **"政策追涨"是追涨变体**——市场已定价的利好进去就是接盘
5. 追涨类因子在 A 股短期是负期望（涨停次日买入月均 -28.4%）

## 回测纪律（docs/kuixue_validation_standard.md）

- 基准：沪深300 当日涨跌幅（后被证明应视标的改中证500）
- 五档分组单调性检验，剔除涨跌停与 ST
- 连续 5 日中 4 日单调 = 初步有效；方向随机 = 停下来换因子
